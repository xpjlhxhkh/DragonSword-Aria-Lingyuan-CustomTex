# 龙之剑：觉醒 · Aria → 泠鸢（公式服3.0 栗子发）· 自改贴图版

这是「龙之剑：觉醒」中把**阿莉娅（Aria）**替换成**泠鸢（公式服3.0 栗子发）**的 mod 的 **自改贴图版本**。

模型部分与主项目 [DragonSword-Aria-Lingyuan-Mod](https://github.com/xpjlhxhkh/DragonSword-Aria-Lingyuan-Mod) 的 **v1.2 完全一致**，唯一区别是**图集贴图做过手动修改**（皮肤/服装的调色、局部细节），改好的贴图已直接打进 pak。

## 安装

1. 下载 `zzzzDS_LingyuanGS_CustomTex_P.pak`
2. 放到 `<游戏目录>\DS\Content\Paks\~mods\`
   - 没有 `~mods` 文件夹就自己新建；注意是 `Paks` 下的 `~mods`，不是 `Mods`
3. 重启游戏生效（换 pak 必须重启）

游戏目录参考：`...\SteamLibrary\steamapps\common\DragonSword  Awakening\`（注意目录名里是两个空格）

> `~mods` 里同一个角色请只放一个 pak，多个会互相覆盖。

## 这一版包含什么

| 项目 | 说明 |
|---|---|
| 服装 | 公式服 3.0，按上表三种裁剪方式之一 |
| 手指 | 每根手指独立按指骨弯曲（硬分指权重，单弯一指邻指不动） |
| 袖子 | 法线投射绑定（上背/腋下不再洗出、抬臂不撕） |
| UI | 英雄页立绘 / 头像 / 图标换成 2D 立绘（取原图左侧 66%，避免被游戏裁切） |
| 贴图 | **本仓库特色**：4096 图集经过手改（皮肤格调色、局部细节） |

pak 共 82 个文件：角色相关 63 个（网格/材质/贴图）+ UI 19 个。
网格 4 个 section、183 根骨、**不打包 Skeleton**（引用游戏自带骨架）。

## 自己改贴图

仓库里附了可编辑的图集与索引：

- `lygs_atlas_v5.png` —— 4096×4096，**8×8 格，每格 512px，一个材质占一格**
- `atlas_grid.png` —— 格子编号对照图
- `atlas_legend.txt` —— 格子 → 材质名

主要格子：脸 (7,6)、瞳孔 (7,4)、前发 (2,1)、体 (6,1)、臂 (6,2)、服外-布 (5,3)、服纱-袖 (5,0)。
> 图例里的行列是**从上往下**数的（第 X 列、第 Y 行）。

改完直接替换 pak 里的 `T_hanser_atlas` / `ch_aria_base_*_col` 再重新打包即可。

## 已知限制

- 模型**没有布料/头发物理**（KawaiiPhysics 未适配）
- 手指是"整片按指骨弯"：模型四根手指根部是连着的，做不了逐指完全独立
- epic / rare 换装的外观没有替换，仍是游戏原模型
